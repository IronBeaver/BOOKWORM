# A simple BOOKWORM testing checklist

Use a book you are allowed to copy. Keep your original EPUB safe. You do not need
to send logs or share the book itself to report a problem.

## Everyday reading — stable v1.0 and development builds

- Open BOOKWORM. Can you see your existing books and bundled Frankenstein?
- Import an EPUB. Does its title/author appear, and can you open it?
- Read several pages. Try the left/right tap zones and show/hide centre controls.
- Open Contents and move to another chapter, then return to the library.
- Change reading size, colours or mode. Is the text still comfortable to read?
- Close and reopen the book, then restart the app. Is your approximate position saved?
- Open book options with long-press or the visible menu. Try a leather colour.
- Turn Wi-Fi off and read an already imported book. It should still work.

## Physical bookshelf — development v1.1 features

- Switch between grid, classic covers and spine shelves in Settings > Bookshelf.
- Enable/disable dimensional effects. Are covers and labels clear?
- Tap a spine. Is the selected book clear, with the correct preview and Read action?
- Open options, dismiss the preview and try another spine. Do targets feel usable?
- Try larger system text, keyboard/D-pad or TalkBack if you already use them.

## Experimental catalog — development v1.2 only

- With Wi-Fi enabled, open Settings > Discover > Browse Books.
- Try Popular, a title/author search and an optional language such as `en`.
- Report whether it connects, times out or shows another message. A timeout is
  already known on the reference SM-T280; its cause has not been established.
- If results work, request a cover, inspect details and download one EPUB.
- Try cancellation during transfer. Final atomic import cannot be cancelled.
- If import succeeds, use Open Book, then read it again offline.
- Do not repeatedly retry a blocked/busy service or download many books for testing.

## What to tell us

Describe what you did, expected and saw. Include manufacturer/model, Android
version and CPU architecture if known; installation result, import/reading result,
shelf performance, network result and any crashes/confusing behavior. A screenshot
is optional. Remove personal details before sharing. Never uninstall as a routine
update test: uninstalling can erase the library and preferences.
